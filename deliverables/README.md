## Repository

Published at https://github.com/ananydoneria/tripmate (private). To share it with faculty or group members, add
them as collaborators (`gh repo edit` / Settings → Collaborators) or make it public
(`gh repo edit ananydoneria/tripmate --visibility public --accept-visibility-change-consequences`).

`.env` (your API key), `.venv/` and `.cache/` are excluded by `.gitignore`.
